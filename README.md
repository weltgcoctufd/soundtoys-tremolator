## Overview

Soundtoys Tremolator models classic analog tremolo circuits with smooth amplitude modulation, tempo synchronization, and a pattern editor for complex rhythmic tremolo sequences.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Tremolator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Analog Model** | Optical and bias tremolo circuit emulations for vintage character |
| **Tempo Sync** | Modulation rate locked to DAW BPM with note division selector |
| **Pattern Editor** | Step-programmable tremolo patterns for rhythmic amplitude shaping |
| **Stereo Offset** | Left/right phase offset for stereo image animation |
